# ``InAppPurchase``

Load products, make purchases, and track entitlements with StoreKit 2.

## Overview

``PurchaseStore`` is the observable state a view renders. It reads from the App Store in an app,
or from the mock client in `InAppPurchaseTesting` in a test or preview.

## Topics

### State

- ``PurchaseStore``

### Values

- ``PurchaseError``
- ``PurchaseOutcome``
- ``PurchaseProduct``
- ``PurchaseTransaction``
